Database System Design for Perfect Day

Project Overview

Developed a comprehensive database management system for Perfect Day, a Berkeley-based biotech startup that produces ProFerm™ - an animal-free whey protein used in dairy alternatives. The project involved designing a complete relational database architecture to streamline order tracking, demand forecasting, and production planning across their supply chain operations.

Key Achievements

  • Designed 20-table relational schema with complete EER diagram based on manufacturing and supply chain frameworks
  • Implemented normalization up to BCNF to eliminate data redundancy and ensure data integrity
  • Created SQL queries for aggregate production planning using Economic Production Quantity (EPQ) model
  • Developed forecasting accuracy analysis using MSE and RMSE metrics to optimize inventory management
  • Architected end-to-end order tracking system from forecast creation to warehouse fulfillment

Final presentation showcasing the EER diagram, relational schema, normalization process, and SQL queries for production planning and forecasting accuracy analysis.
